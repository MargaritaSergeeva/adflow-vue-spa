# AdFlow

`AdFlow` is a production-like Vue 3 SPA that simulates an adtech workspace for campaign operations, reporting, and team collaboration.

## Current Stage

This repository is in the bootstrap phase. The first iteration focuses on:

- application foundation
- modular architecture
- bilingual setup (`ru` / `en`)
- light and dark themes
- mock-ready dashboard, campaigns, and reports screens
- modern DX tooling

## Stack

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- TanStack Query
- Axios
- Tailwind CSS v4
- reka-ui
- Vue I18n
- MSW
- Vitest
- Playwright
